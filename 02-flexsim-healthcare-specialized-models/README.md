# FlexSim Healthcare — Specialized Simulation Models

This folder covers selected healthcare simulation functions using **FlexSim Healthcare** and its 3D people-modeling and Process Flow capabilities. The models focus on dashboards, patient relocation, and laboratory workflows implemented with two different types of process flow.

## Models Covered

### 1. Healthcare Dashboards

**Model:** `healthcare-dashboards.fsm`

Focuses on the use of dashboards in a FlexSim Healthcare simulation. Dashboards provide a way to display and examine information generated by a model. The specific charts, measures, and dashboard configuration should be inspected in FlexSim before reporting numerical findings.

**Key topic:** Healthcare simulation dashboards and model-data presentation.

### 2. Patient Relocation

**Model:** `patient-relocation.fsm`

Focuses on patient relocation within a healthcare simulation. It provides a separate model for studying how patient movement is represented and coordinated in the model's logic.

**Key topic:** Patient movement and relocation logic.

### 3. Patient Labs — General Process Flow

**Model:** `patient-labs-general-process-flow.fsm`

Presents a patient laboratory workflow using a **general process flow**. General process flows are useful for managing logic that does not have to be defined inside one patient-specific process flow.

**Key topic:** Laboratory activities represented using general Process Flow logic.

### 4. Patient Labs — Patient Process Flow

**Model:** `patient-labs-patient-process-flow.fsm`

Presents the patient laboratory topic using a **patient flow process flow**. This version provides a companion example to the general-process-flow implementation.

**Key topic:** Laboratory activities represented through patient-specific flow logic.

## General Process Flow vs. Patient Process Flow

The two laboratory files should be kept together. They allow the same healthcare topic to be examined from two process-flow organization approaches:

| Approach | Modeling perspective | File |
|---|---|---|
| General process flow | Organizes model logic in a general-purpose process flow | `patient-labs-general-process-flow.fsm` |
| Patient process flow | Organizes activities around patient-specific flow | `patient-labs-patient-process-flow.fsm` |

The exact differences in activities, parameters, routing, and resulting performance must be confirmed by opening the two models. No claim of equivalence or performance improvement is made here.

## Working with the Models

1. Open an `.fsm` file in a compatible version of FlexSim.
2. Inspect its 3D model and available Process Flow tabs.
3. Review the activity configuration, objects, and model-specific assumptions.
4. Reset and run the model to observe the healthcare workflow.
5. Review available dashboards or statistics, where provided.

See [REQUIREMENTS.md](REQUIREMENTS.md) for software and compatibility notes.

## Reference

These files are associated with the **FlexSim Healthcare Instructional Video Series**. FlexSim Healthcare provides healthcare-oriented objects and activities for modeling people, patient care operations, resources, and related workflows.

These models document instructional examples; results and operational conclusions should be checked in FlexSim before they are reported.
