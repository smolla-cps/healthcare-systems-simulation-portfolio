# Healthcare Laboratory Simulation and Dashboard Visualization

This folder contains three FlexSim Healthcare simulation models from the FlexSim Healthcare Instructional Video Series. The models explore two approaches to organizing patient laboratory activities in Process Flow and a separate example of dashboard visualization for healthcare simulation.

## Models Covered

### 1. Healthcare Dashboard Visualization

**File:** `healthcare-dashboard-visualization.fsm`

Introduces the use of dashboards to visualize information generated by a healthcare simulation. The model can be used to inspect how model data are presented during simulation and how dashboards support the interpretation of healthcare operations.

**Focus:** Healthcare simulation dashboards, monitoring, and data visualization.

### 2. Patient Laboratory — General Process Flow

**File:** `patient-laboratory-general-process-flow.fsm`

Demonstrates a patient laboratory example organized with a **general process flow**. This approach supports coordinating activities through a general-purpose process-flow structure rather than organizing the entire logic around an individual patient's dedicated flow.

**Focus:** Laboratory workflows and general Process Flow logic.

### 3. Patient Laboratory — Patient Process Flow

**File:** `patient-laboratory-patient-process-flow.fsm`

Demonstrates the patient laboratory topic using a **patient process flow**, with activities organized around the path and actions of a patient in the healthcare model.

**Focus:** Patient-oriented laboratory workflows and patient-specific Process Flow logic.

## Comparing the Laboratory Models

| Aspect | General Process Flow | Patient Process Flow |
| --- | --- | --- |
| Model file | `patient-laboratory-general-process-flow.fsm` | `patient-laboratory-patient-process-flow.fsm` |
| Logic organization | General-purpose process flow | Patient-associated process flow |
| Main point to examine | How laboratory-related tasks are coordinated | How laboratory activities are connected to patient movement and behavior |

Both models cover patient laboratory simulation, but use different Process Flow organizations. Their detailed settings and outputs should be examined in FlexSim before making claims about differences in performance.

## Opening and Exploring the Models

1. Open an `.fsm` file in a compatible version of FlexSim.
2. Review the 3D model, relevant Process Flow tabs, and, for the dashboard model, the dashboard views.
3. Reset and run the simulation to observe its behavior.
4. Compare how the two laboratory examples structure their process-flow logic.
5. Review the dashboard's actual charts and measures in FlexSim rather than assuming particular performance results.

See [REQUIREMENTS.md](REQUIREMENTS.md) for software and compatibility information.

## Source and Scope

The models are based on the **FlexSim Healthcare Instructional Video Series**. The descriptions identify the topics demonstrated by the supplied model files. Simulation runs and numerical performance results have not been independently verified for this documentation.
